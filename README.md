# One Emoji, One Smile — Holding Back Tears

A one-emoji entry for the make.fun bounty of the same name. No words,
no caption — just the face holding back tears, warm enough to make a
judge smile.

Running `python3 main.py` builds the emoji from its Unicode code
point and writes that single character to `/output/entry.txt`. The
file holds exactly 4 bytes, with no trailing newline.
